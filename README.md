- 🔭 **Building:** SaaS platforms, business tools, and AI automation workflows
- 🧩 **Frontend:** Angular, React, TypeScript, JavaScript, HTML, CSS
- ⚙️ **Backend:** Node.js, Express.js, REST APIs, authentication and role-based access
